# Model Card — PAIMANA AI Risk Prediction & Attribution Engine (Model B)

## 1. Model Details
- **Organization / Team:** PAIMANA AI (Smart India Hackathon Team SIH26103)
- **Model Name:** PAIMANA Infrastructure Risk Predictor (Model B)
- **Model Type:** Gradient Boosted Decision Trees (`XGBRegressor` + `XGBClassifier`) with SHAP TreeExplainer attribution

---

## 2. Intended Use
- **Primary Use:** Decision support for Ministry of Statistics and Programme Implementation (MoSPI) Infrastructure and Project Monitoring Division (IPMD) officers, project directors, and state nodal authorities.
- **Key Tasks:**
  1. Real-time composite project risk scoring ($0-100$).
  2. Time overrun probability estimation ($P(\text{overrun}) \in [0, 1]$).
  3. Mathematically reconciled feature attribution via genuine `shap.TreeExplainer`.
  4. Counterfactual "What-If" intervention simulation with exact risk delta calculations.
- **Out-of-Scope Uses:** Automated financial disbursement withholding without human-in-the-loop engineering audit; punitive contractor debarment without statutory notice.

## 3. Training Data & Calibration Disclosure
> [!IMPORTANT]
> **Data Transparency Disclosure:**  
> Real row-level PAIMANA government infrastructure project telemetry and dispute documentation are restricted under Government of India data governance protocols.  
> To respect data boundaries while maintaining empirical validity, Model B was trained on a **5,000-project synthetic dataset** generated by `ml/generate_dataset.py`, rigorously calibrated to MoSPI's publicly released aggregate infrastructure statistics:
> - **Cost Distribution:** Power-law and log-normal distributions mirroring central sector projects ($\ge ₹150\text{ Cr}$).
> - **Delay Prevalence:** Calibrated to historical MoSPI flash report averages (~40–48% of projects experiencing schedule overruns).
> - **Sector Weights:** Roads, Railways, Bridges, and Power corridors sampled proportional to national infrastructure pipeline allotments.
> - **Ground Friction Signals:** Realistic correlation structures between statutory right-of-way disputes, multi-tier subcontracting depth, Running Account (RA) billing progress mismatches, and disbursement delays.

## 4. Feature Space
Model B takes 12 standardized features:
1. `sector`: Infrastructure sector (`Roads`, `Bridges`, `Railways`, `Power`).
2. `land_clearance_status`: Corridor acquisition state (`Clear`, `Pending`, `Disputed`).
3. `cost_original`: Sanctioned baseline capital expenditure (in ₹ Crores).
4. `cost_revised`: Latest revised administrative cost estimate (in ₹ Crores).
5. `duration_months`: Sanctioned project execution duration.
6. `elapsed_months`: Months elapsed since physical site mobilization.
7. `planned_progress`: Cumulative baseline physical schedule milestone target ($0-100\%$).
8. `actual_progress`: Ground-verified cumulative physical completion ($0-100\%$).
9. `payment_delay_days`: Average disbursement turnaround delay on certified contractor bills.
10. `subcontracting_depth`: Number of subordinate contracting tiers ($0$: direct EPC, $2+$: petty sub-letting).
11. `design_scope_change_count`: Number of sanctioned engineering or alignment revisions.
12. `billing_progress_mismatch_pct`: Variance between financial expenditure claims and certified physical progress.

## 5. Explainability & Mathematical Reconciliation Guarantee
- **Algorithm:** Lundberg & Lee (2017) SHAP TreeExplainer.
- **Reconciliation Guarantee:**
  $$\text{base\_value} + \sum_{i=1}^{M} \text{SHAP}_i = \text{raw\_prediction}$$
  Exact to floating-point precision ($10^{-5}$ tolerance verified in automated CI).
- **Dual-Mode Attribution:**
  - **Risk Escalation Mode ($\text{pred} \ge \text{base\_value}$):** Ranks features with positive SHAP values (risk drivers driving score above benchmark population mean).
  - **Protective / Stabilizing Mode ($\text{pred} < \text{base\_value}$):** Ranks features with negative SHAP values (protective guardrails sustaining on-time, disciplined delivery).
- **Hard Constraint:** Zero disguised `if/else` approximations or hand-rolled deltas.

---

## 6. Limitations & Governance
- Model predictions represent statistical risk signals, not deterministic engineering guarantees.
- Extreme outlier weather events (e.g. cloudbursts, unseasonal floods) require field officer manual override via `daily_entries`.
- All automated intervention suggestions must be ratified by a certified Divisional Engineer.
